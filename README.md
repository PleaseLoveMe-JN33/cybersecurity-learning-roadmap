# Cybersecurity Learning Roadmap

My open-source learning journey in cybersecurity, networking, Linux, and Python.

This repository documents my daily learning, hands-on practice, technical notes, and progress toward a career in cybersecurity.

- Build a solid foundation in computer networks and Linux.
- Learn Python for automation and security analysis.
- Understand cybersecurity fundamentals and security operations.
- Complete practical labs and develop portfolio projects.
- Improve technical documentation and collaboration skills with Git and GitHub.
