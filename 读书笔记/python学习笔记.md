## 第一章   字面量

### 1.1   掌握字面量的含义

什么是字面量 ？

代码中，被写在代码中的**固定的值**

python中常用的值类型如下

**数字（Number）**

整数（int），如10和 -10

浮点数（float），如13.14

复数（complex），如4 + 3j，以j结尾表示复数

布尔（bool）表达现实生活中的逻辑，即真和假，True（1）为真，False（0）为假

**字符串（string）**

描述文本的一种数据类型，由任意数量的字符组成

**被双引号包围起来的，就是字符串**

**列表（List）**

有序的可变序列，python中用的最频繁的数据类型，可以有序记录一堆数据

**元组（Tuple）**

有序的不可变序列，可以有序的记录一堆不可变的python数据集合

**集合（Set）**

无序不重复集合，可无序记录一堆不重复的python数据集合

**字典（Dictionary）**

无序Key-Value集合，可无序记录一堆Key-Value型的python数据集合

### 1.2   变量

什么是变量 ？

**在程序运行时**，能够**储存**计算结果或能**表示值**的抽象概念

type()语句可以验证数据的类型，用法为**type(被查看的类型的数据)**

| 语句（函数） | 说明                |
| ------------ | ------------------- |
| int(x)       | 将x转换为一个整数   |
| float(x)     | 将x转换为一个浮点数 |
| str(x)       | 将x转换为字符串     |

**万物皆可转字符串，但将字符串转成数字，字符串的内容必须是数字才能成功哦**

#### **1.5.3   格式化的精度控制**

先看代码演示

```
# 代码
name = "JohnWang"
age = 23
stature = 178.45
message = "我的名字是%s,我今年%d岁了，我的身高是%fcm" % (name, age, stature)
print(message)

# 编译结果
我的名字是JohnWang,我今年23岁了，我的身高是178.450000cm
```

Q：为什么浮点数178.45，变成了178.450000输出 ？

A：未进行数字精度的控制

**OK，那怎么进行精度的控制呢 ？**

使用辅助符号 "m.n" 来控制数据的宽度和精度

-  **m**，控制宽度，用数字填写，设置的宽度小于数字本身时不生效
- **.n**，控制小数点精度，用数字填写，会进行小数的四舍五入

举个例子来看

```
# 代码
name = "JohnWang"
age = 23
stature = 178.46
message = "我的名字是%s,我今年%5d岁了，我的身高是%.1fcm" % (name, age, stature)
print(message)

# 编译结果
我的名字是JohnWang,我今年   23岁了，我的身高是178.5cm
```

#### 1.5.4   字符串格式化的快捷方式

Q：用%符号来占位很方便，还可以做精度控制，有没有更快捷的表示方式呢 ？

A：有的兄弟，有的，通过**f"内容{变量}"**来表示，**但是浮点数输出不会做精度控制，你输入19.99，只会输出19.99，而不是19.990000**

示例如下

```
# 代码
name = "鸣上悠"
age = 17
stature = 188.55
print(f"我叫{name}，现年{age}岁，身高是{stature}cm")

# 编译结果
我叫鸣上悠，现年17岁，身高是188.55cm
```

#### 1.5.5   对表达式进行字符串格式化

表达式就是一条**具有明确执行结果**的**代码语句**，比如1 + 1，"张三"

**在无需使用变量存储数据时，可以直接格式化表达式来简化代码**

```
print("1 + 1 = %d" % (1 + 1))
print(f"1 * 2 = {1 * 2}")
```
