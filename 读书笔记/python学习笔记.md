## 第一章   字面量

### 1.1   掌握字面量的含义

什么是字面量 ？

在代码中，直接写出来的、表示某个**固定值的东西**

python中常用的值类型如下

**数字（Number）**

整数（int），如10和 -10

浮点数（float），如13.14

复数（complex），如4 + 3j，以j结尾表示复数

布尔（bool）表达现实生活中的逻辑，即真和假，True（1）为真，False（0）为假

**字符串（string）**

描述文本的一种数据类型，由任意数量的字符组成

**被双引号包围起来的，就是字符串**

**列表（List）**

有序的可变序列，python中用的最频繁的数据类型，可以有序记录一堆数据

**元组（Tuple）**

有序的不可变序列，可以有序的记录一堆不可变的python数据集合

**集合（Set）**

无序不重复集合，可无序记录一堆不重复的python数据集合

**字典（Dictionary）**

无序Key-Value集合，可无序记录一堆Key-Value型的python数据集合

#### **1.5.3   格式化的精度控制**

先看代码演示

```
# 代码
name = "JohnWang"
age = 23
stature = 178.45
message = "我的名字是%s,我今年%d岁了，我的身高是%fcm" % (name, age, stature)
print(message)

# 编译结果
我的名字是JohnWang,我今年23岁了，我的身高是178.450000cm
```

Q：为什么浮点数178.45，变成了178.450000输出 ？

A：未进行数字精度的控制

**OK，那怎么进行精度的控制呢 ？**

使用辅助符号 "m.n" 来控制数据的宽度和精度

-  **m**，控制宽度，用数字填写，设置的宽度小于数字本身时不生效
- **.n**，控制小数点精度，用数字填写，会进行小数的四舍五入

举个例子来看

```
# 代码
name = "JohnWang"
age = 23
stature = 178.46
message = "我的名字是%s,我今年%5d岁了，我的身高是%.1fcm" % (name, age, stature)
print(message)

# 编译结果
我的名字是JohnWang,我今年   23岁了，我的身高是178.5cm
```

range(num1, num2,step)

#### 5.4.3   while和for循环对比

- while循环可用于任何想要循环的场景
- for循环适用简单固定次数循环的场景
- while循环能无限，for循环是做不到的
- while循环可以自定义循环条件控制，for循环是做不到的

### 5.7   数据容器（序列）的切片

序列的概念：内容连续，有序，可使用下标索引的一类数据容器

**列表，元组，字符串**都可视为序列

切片：从一个序列中，取出一个子序列

**语法：序列[起始下标:结束下标:步长]**

- 起始下标，表示从何处开始，留空的话意味从头开始
- 结束下标，表示何处结束，**假如为5，则意为到5结束但不包括5**，留空意味一直到结尾
- 步长表示依次取元素的间隔
- 步长1，一个个取元素
- 步长2，每次跳1个取元素，以此类推
- 步长为负，反向取

**切片操作不会影响序列本身，只会得到一个新的序列**
